# 遇到问题？请到 Steam 讨论帖留言

> 本文是 Steam 创意工坊讨论帖 [Having a problem? Post it here](https://steamcommunity.com/workshop/filedetails/discussion/3799476240/563668239243120957/) 的翻译。如需提问或报告问题，请在该讨论帖中留言——不必使用英文，直接用中文写即可。

任何出错的情况都可以在 [Steam 讨论帖](https://steamcommunity.com/workshop/filedetails/discussion/3799476240/563668239243120957/) 中反馈——崩溃、某位玩家一直无法完成加入、画面显示不正确、一局游戏出了故障，等等。

**如果你的手机或平板电脑完全打不开加入页面**，请先阅读 [手机或平板电脑无法连接？](phone-connection-troubleshooting.md)——那里详细介绍了 Wi-Fi、防火墙和路由器，大多数连接问题都能在那里解决。

---

## 需要提供的信息

不必回答所有问题——前两项比其余所有加起来都更有价值。

### 1. 发生了什么，以及你原本预期会怎样

一两句话就够了。如果屏幕上出现了错误提示，请原样照抄，包括下方任何较小的灰色文字。附上照片或截图就再好不过了。

### 2. 如果问题出在加入或大厅：连接报告

*如果你的问题发生在之后——对局中或游戏本身——请直接跳到第 3 步。*

在大厅中打开 **Couch Co-Op 二维码** 界面。**连接** 面板就在上面，位于二维码下方。出错的项目会保留在 **连接问题**（后面带有数量）下。

选中失败的那一行，按下 **复制报告**，然后粘贴到你的留言中。对于加入问题，这是你能附上的最有用的信息：其中已经包含失败的步骤、耗时、主机自己的诊断，以及下文所述日志文件的路径。

### 3. 日志文件

日志有两种，哪一种重要取决于具体问题。

**主游戏日志**，位于主机电脑上：

- Windows：`%APPDATA%\SlayTheSpire2\logs\godot.log`
- Linux：`~/.local/share/SlayTheSpire2/logs/godot.log`
- macOS：`~/Library/Application Support/SlayTheSpire2/logs/godot.log`

**每位玩家的日志**。每位加入的玩家都会在主机电脑后台运行一份属于自己的游戏副本，每份副本都有自己的日志。**如果某位玩家卡在加入过程中，能解释原因的就是这个文件**——上面的主日志通常不会说明。

玩家从 2 开始编号，所以第一位加入你的人是 `slot-2`。在 Linux 上，该玩家的日志位于：

`~/.local/share/SlayTheSpire2/couch-coop/headless-slots/slot-2/SlayTheSpire2/logs/godot.log`

（没错，`SlayTheSpire2` 确实出现了两次——这不是笔误。）在 Windows 和 macOS 上也是同样的结构，位于上面列表中的文件夹下。在某些环境中，它则是位于 `couch-coop/seat-logs/slot-2.log` 的单个文件。无论哪种情况，**第 2 步中的报告都写明了确切路径**，所以先复制报告能省去你到处找的麻烦。

**哪些行重要**。在任一文件中，有用的是包含 `[couchcoop]` 的行（形如 `[INFO] [couchcoop] ...`），以及所有 `[ERROR]` 行，即使其中没有提到 couchcoop。通常光这些行就足够了。

**在粘贴整份日志之前**：Steam 讨论帖是公开的，而日志中包含你自己的 **SteamID64**（一串以 7656 开头的长数字，指向你的 Steam 个人资料），以及文件路径中你电脑的 **用户名**。日志*不*包含密码，也不包含其他玩家的账户——只有你的。如果你不想公开这些，粘贴前对这两项做一次查找替换就够了；或者只贴出 `[couchcoop]` 和 `[ERROR]` 行，如果需要更多信息，我会再问你。

### 4. 版本和模组

- 你使用的是游戏的 **稳定** 分支还是 **公开测试** 分支。
- **安装了哪些其他模组**。每个在后台运行的玩家副本都会加载与主机相同的模组，所以即使主机自己的游戏看起来完全正常，其他模组也可能导致某位玩家无法完成加入。
- 主机的操作系统。
- CouchCoop 的版本（如果你知道的话）——否则我会默认你用的是最新版。

### 5. 任何有助于缩小范围的信息

- 每次都会发生，还是只是偶尔发生？
- 每位玩家都会遇到，还是只有一位？
- 以前是否正常过？之后有没有什么变化——游戏更新、新模组？

## 报告前值得了解的一件事

启动一位玩家的游戏最多可能需要一分钟，在较慢的电脑上几乎会用满这段时间。这是正常现象，并非故障。在此过程中，加入页面会在“正在加入…”下方计时并切换阶段——如果那一行还在变化，就说明还没有出错，请保持页面打开。
